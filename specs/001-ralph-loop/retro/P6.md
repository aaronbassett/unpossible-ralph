- Regex with multiline mode handles line-by-line matching cleanly
- (result, was_explicit) tuple return makes implicit REPEAT handling clear

## Workarounds & Solutions
- Use `(?m)` multiline mode so `^` matches line start, not just string start
- Collect all matches then take last for "last wins" behavior (D22)
- Return was_explicit=false when defaulting to Repeat for warning purposes
