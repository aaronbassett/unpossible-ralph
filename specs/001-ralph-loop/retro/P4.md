# Phase 4 Retrospective: Core Loop Execution [US2]

## What Worked Well
- Tokio process execution with async/await is clean
- nix crate handles process group creation and signals well
- String::from_utf8_lossy handles invalid UTF-8 per FR48

## What Didn't Work
- `loop` is a reserved keyword in Rust - had to use `r#loop` module name

## Workarounds & Solutions
- Use `r#loop` to escape the reserved keyword for module name
- Process group killing via `setsid()` in pre_exec + `killpg()`
- Separate capture.rs for output utilities keeps mod.rs focused

## Packages & Dependencies
- nix 0.29 with signal and process features for Unix process control
- libc 0.2 for SIGKILL constant

## Patterns & Code
- AgentRunner pattern: construct with timeout, run command
- LoopState tracks iteration_count, retry_count, next_prompt
- TemplateContext with HashMap for variable substitution
- Regex with lazy_static for {{variable}} pattern matching
